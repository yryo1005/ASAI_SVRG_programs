# report_004

本レポートは，`.orders/order_004.md` の指示に基づき実施した，論文『平均スナップショット近似に
基づく確率的分散削減勾配法（Averaged Snapshot Approximate Incremental SVRG，ASAI SVRG）』
（`references/ASAI_SVRG_paper.pdf`）の4.2節（CNNとCIFAR-10の多値分類問題）に対応する数値実験の
実施内容と結果をまとめたものである．Ex001（4.1節）との比較設計上の関係は
`.reports/report_001.md`〜`.reports/report_003.md` を参照のこと．

## 1. 実施内容

### 1.1 作成したプログラム

- `programs/ex002_cifar10_cnn/data.py`：CIFAR-10データセットの取得・前処理．
- `programs/ex002_cifar10_cnn/model.py`：3つの畳み込み層と1つの全結合層から成るCNN
  （`CNNModel`），`load_model`，`set_model_params`．
- `programs/ex002_cifar10_cnn/train.py`：`loss_func`／`metrics_func`／`iteration`／`epoch`／
  `train` の関数構成（`@.ai/ai-dev-kit/machine_learning.md`）に従い，4手法 x 5Seedの学習を
  実行するスクリプト．
- `tests/test_cnn_model.py`：CNNモデルの単体テスト（4件，全て合格）．

最適化手法クラス（`programs/optimizers/optimizers.py`）はEx001から変更せずそのまま再利用した．

### 1.2 `@.ai/ai-dev-kit/root_prompt.md` への準拠方針

`.orders/order_004.md` は，以降の指示ではmodel.py／train.py等の記述を
`@.ai/ai-dev-kit/root_prompt.md`（`@.ai/ai-dev-kit/machine_learning.md` を含む）の指示に必ず
従うよう求めている．そのため `train.py` では `loss_func`／`metrics_func`／`iteration`／
`epoch`／`train` の関数構成を用いた．ただし，SVRG系手法（SVRG，NFG SVRG，ASAI SVRG）は
同一ミニバッチに対して現在のパラメータ w_s^k とスナップショット z_s の双方における勾配を
必要とし，自動微分は実際にforwardした計算グラフに対してのみ機能するため，`iteration` 関数を
スナップショット専用モデル `snapshot_model` を任意引数として受け取れるよう拡張している．
この点のみが標準テンプレートからの変更点である．

Ex001とは異なり，Ex002では「1エポック＝1回のDataLoader走査（ミニバッチ数K個）」がそのまま
SVRGの内部ループに対応するため，`epoch` 関数がSVRG系手法の内部ループ本体を兼ねる，
Ex001よりも標準テンプレートに近い自然な構成となっている．外部ループ（`begin_epoch`/
`end_epoch`/スナップショットの更新）は `train_variance_reduced()` が担う．

### 1.3 実験条件

**データセット**：CIFAR-10（`torchvision.datasets.CIFAR10`）．学習用データ数
$ N_{\mathrm{train}} = 50000 $，検証用データ数 $ N_{\mathrm{test}} = 10000 $（公式の分割）．
各画像は $ 32 \times 32 $ のカラー画像（チャネルごとに平均・標準偏差で標準化）．

**モデル・目的関数**：3つの畳み込み層（各層の後にReLUと2x2最大値プーリング，チャネル数
$ 3 \to 32 \to 64 \to 128 $）と1つの全結合層から成るCNN．目的関数は論文(39)式に対応する
多値交差エントロピー損失であり，L2正則化は用いない．

**比較手法**：SGD，SVRG，NFG SVRG，ASAI SVRGの4手法．

**ミニバッチ学習**：4.1節のオンライン学習（ミニバッチサイズ1）とは異なり，実際のユースケースを
想定し，ミニバッチサイズ128の下でミニバッチ学習を行った．SVRG系手法の内部ループ長 $ K $ は
1エポックあたりのミニバッチ数（$ K = \lceil N_{\mathrm{train}} / 128 \rceil = 391 $）とした．

**ハイパーパラメータ**：非凸設定のためリプシッツ定数は陽に求まらず，学習率は理論的な導出では
なく試行的に定めた（詳細は1.4節）．最終的に全手法・全Seed共通で学習率 $ \eta = 0.001 $，
ミニバッチサイズ128，エポック数15を用いた．Weight Decay等，一般に収束や汎化を改善しうる
付加的な工夫は加えていない．

**評価指標**：勾配計算回数（オラクル呼び出し回数），エポック数，経過時間の3種類の横軸と，
目的関数の値・分類精度・フル勾配の近似誤差 $ \|\mathbf{e}_s\|^2 $ の3種類の縦軸を用いた．
非凸設定のため目的関数の真の最適値 $ f(\mathbf{w}^*) $ は求まらないため，4.1節で用いた
目的関数の「誤差」 $ f(z_s) - f(\mathbf{w}^*) $ の代わりに，目的関数の値 $ f(z_s) $
（学習用データに対する損失）自体を記録した．分類精度は検証用データに対する値である．
オラクル呼び出し回数は1エポックあたり，SGDが $ N_{\mathrm{train}} $ 回，SVRGが
$ 3N_{\mathrm{train}} $ 回，NFG SVRG・ASAI SVRGが $ 2N_{\mathrm{train}} $ 回であり，
4.1節と同様の計算方法である．

### 1.4 学習率の選定過程（発散の確認と対処）

`.orders/order_004.md` の指示「適当に学習率を定めてください」に従い，まずCNN・SGD系手法の
学習率として一般的な値である $ \eta = 0.01 $ で予備実験を行った．その結果，SGD・SVRGは
安定して学習が進行した一方，NFG SVRG・ASAI SVRGは学習の途中（8〜9エポック目付近）で
目的関数の値が急激に増大し，最終的に発散（NaN）する現象が5Seed中，複数のSeedで観測された．

$ \eta = 0.005 $ に低下させたところ，ASAI SVRGは15エポックにわたり安定したが，NFG SVRGは
なお11エポック目付近で発散した．$ \eta = 0.001 $ まで低下させたところ，NFG SVRGを含む
全手法が15エポックにわたり安定して学習することを確認したため，この値を採用した．

この現象は，論文Theorem 2が示す「ASAI SVRGの近似誤差はNFG SVRG以下である」という関係と
整合的である．NFG SVRGはスナップショット点 $ \mathbf{z}_{s+1} $ を内部ループのパラメータ列
から一様ランダムに1点選ぶ一方，ASAI SVRGはパラメータ列の平均を用いる．非凸なCNNの損失
局面では，パラメータがエポック内で大きく移動しうるため，NFG SVRGがランダムに選んだ
スナップショットが現在のパラメータから大きく乖離している場合，補正勾配
$ \mathbf{v}_s^k = \nabla f_n(\mathbf{w}_s^k) - \nabla f_n(\mathbf{z}_s) + \mathbf{g}_s $
の分散が増大し，学習を不安定化させたと考えられる．ASAI SVRGの平均化によるスナップショットの
平滑化が，この不安定性を緩和していると解釈できる．

## 3. 考察

**理論解析の範囲を超えた設定における妥当性**：CNNとCIFAR-10による本実験は，目的関数が非凸で
あり，論文の理論解析（Assumption 1〜4）の前提を満たさない．そのため，SVRGの線形収束や
NFG SVRG／ASAI SVRGの誤差床への収束といった定理の主張がそのまま成り立つ保証はない．
実際，15エポックという限られた学習期間では，4手法の目的関数の値・分類精度は互いに近い水準
（損失1.72〜1.75，精度39〜41%）にとどまり，Ex001（4.1節）で観測されたような手法間の明確な
収束速度・誤差床の差は，目的関数の値や分類精度の指標では明瞭には観測されなかった．これは
非凸設定における学習初期の段階を切り取った実験であり，理論的な誤差床の議論がそのまま当てはまる
局面ではないことを踏まえると，妥当な結果である．

**近似誤差 $ \|\mathbf{e}_s\|^2 $ におけるASAI SVRGの優位性**：一方で，フル勾配の近似誤差
（図2.1下段，表2.2）については，非凸設定でも論文Theorem 2の主張と整合する結果が明瞭に得られた．
ASAI SVRGの近似誤差の平均値（$ 2.8 \times 10^{-5} $）は，NFG SVRGの平均値
（$ 1.85 \times 10^{-3} $）よりも一貫して小さく，約65分の1の水準であった．この差は，Ex001
（凸設定，約2.2分の1）よりもむしろ非凸設定において顕著であり，1.4節で述べた通り，NFG SVRGの
ランダムなスナップショット選択が非凸な損失局面でより不安定になりやすいこと，ASAI SVRGの
平均化によるスナップショットの平滑化がこれを緩和することを裏付けている．なお，この近似誤差の
差が，学習の安定性（学習率0.005までの発散有無）という形で最も顕著に現れた点は，本実験を通じて
得られた新たな知見である．

**SVRGとSGDの比較**：SVRGはフル勾配計算により $ \mathbf{e}_s = \mathbf{0} $ が厳密に成り立ち，
目的関数の値・分類精度ともにSGDとほぼ同等の水準で推移した．非凸設定では，SVRGの分散削減が
理論的に保証する優位性は成り立たないため，SGDと同程度の結果になったこと自体は理論と矛盾しない．
一方，勾配計算回数の観点では，SVRGはSGDの約3.07倍（2,300,000対750,000）のオラクル呼び出しを
要しており，同等の学習進捗を得るための計算コストはSGDが有利であった．

**経過時間について**：SVRG系3手法はいずれも経過時間が約380〜390秒であり，SGD（約206秒）の
約1.9倍であった．これは，SVRG系手法が1ステップあたり2回の勾配評価（現在のパラメータと
スナップショット）を要すること，およびSVRGはさらに1エポックあたり1回のフル勾配計算を要する
ことに起因する．NFG SVRG・ASAI SVRGはフル勾配計算を要しないが，近似誤差の診断的な評価
（フル勾配との比較）のために別途1エポックあたり1回のフル勾配計算相当のパスを行っており
（オラクル呼び出し回数には計上していない），これがSVRGとほぼ同等の経過時間となった一因である．

## 4. 未解決の論点・今後の検討候補

- 学習率 $ \eta = 0.001 $ は，1.4節で述べた発散の回避を優先して選定した保守的な値であり，
  より高い学習率における各手法の収束速度の限界（特にASAI SVRGがNFG SVRGよりどこまで高い
  学習率に耐えられるかという安定性の定量的な比較）は本実験の範囲外であり，今後の検討課題である．
- エポック数15は実験時間を考慮して選定した値であり，より長期の学習における最終的な分類精度や，
  手法間の収束速度の差が非凸設定でより明確に観測されるかどうかは未検証である．
- 近似誤差 $ \|\mathbf{e}_s\|^2 $ の評価に用いた診断的なフル勾配計算（オラクル呼び出し回数には
  未計上）は，CNNの規模では計算コストが無視できない．手法間の経過時間の比較を行う際は，
  この診断コストが手法間で共通して発生している点に留意する必要がある．
- データ拡張（ランダムクロップ・水平反転等）や学習率スケジューリングは，論文の記載に忠実に
  従うため意図的に用いていない．より高い分類精度を目指す場合は別途検討が必要である．
