# report_051：E3（ImageWoof における実時間の計測）

## 0. 要点

- 実験計画（2026-11-19改訂版）5章の E3 を，本PCで実施した．
  - 条件：ImageWoof・ResNet18（LayerNorm），$ \eta = 10^{-3} $，バッチサイズ128，SVRG系は `last_iterate`，予算 $ \#\mathrm{grad}/N \approx 200 $，シード0〜4．
  - 当初はシード0〜2で実施した．他の実験と揃えるため，シード3・4を追加した．
  - 4手法×5シードの20試行は，全て失敗なく完了した．
- 計測を加えても，学習の計算は変わらない．E0（`ex003`）の `last_iterate` のログと比較すると，学習損失とテスト精度が完全に一致した．比較したのは2エポックの確認の実行と，本実行の最終エポック（ASA・NFG 100，SVRG 67）である．
- 同じ計算でも，試行によって計算機の速度が最大約6%異なった（2.3節）．そのため，手法間の時間の比は，各試行の全勾配の計算の時間で正規化して求めた．
- 論点1：NFG-SVRG・ASA-SVRG の1エポックあたりの時間は，SVRG から全勾配の計算を除いた時間にほぼ等しい．
  - 正規化した比は，NFG-SVRG が1.009，ASA-SVRG が1.022である．
  - 全勾配の計算は，SVRG の1エポックの41.1%を占める．
- 論点2：ASA-SVRG の平均パラメータの逐次更新によるオーバーヘッドは，NFG-SVRG に対して1.2%である（約0.13 s／エポック）．
- 論点3：1エポックあたりの時間は，SGD が ASA-SVRG の0.556倍である（同じシードの比の中央値）．それでも，同じ実時間でのテスト精度は SGD と同等である．
  - $ t = 1000 $ s のテスト精度は，ASA-SVRG・SGD ともに0.450である．
  - 学習損失は，SGD の方が低い．
  - SVRG と NFG-SVRG は，実時間でも ASA-SVRG と SGD を下回る．

| 実行ログ | `outputs/_run_logs/ex009.log`（シード0〜2），`outputs/_run_logs/ex009_seeds34.log`（シード3・4） |

計測の規則は，実験計画5.3節に従う．

- **区間：** 各エポックを4区間に分けて計測した．各区間の前後に `torch.cuda.synchronize()` を挟み，`time.perf_counter()` で計る．
  - `time_optimizer`：内部ループの更新．
  - `time_svrg_full_grad`：SVRG の全勾配の計算．
  - `time_diagnostic`：NFG・ASA の近似誤差の診断のための全勾配の計算．
  - `time_evaluation`：評価．SGD では学習損失の評価も含む．
- **実時間：** $ t $ = `time_optimizer + time_svrg_full_grad` とした．診断と評価の時間は含めない．ω の記録は無効にした．
- **実行の順序：** 全試行を1つずつ，新しいプロセスで逐次に実行した．順序は，シードごとに SGD，SVRG，NFG-SVRG，ASA-SVRG である．
- **GPU の確認：** 各試行の開始前に，GPU のメモリ使用量が2000 MiB 以下であることを確認した．実際の値は約730〜780 MiB であった．
- **共通の設定：** 全手法で，`torch.set_num_threads(1)`，ローダーのワーカー数0，cuDNN の決定論的設定とした．全試行の `config.json` で，計測環境が同一であることを確認した．
- **計測中の CPU 負荷：** シード3の SGD の開始直後に，CPU 上の短いテスト（約3.5 s）を同時に実行してしまった．SGD の1エポックあたりの時間（6.133 s）はシード3の他の手法と同様に上昇しており，このテストによる偏りは見られない．

### 2.3 計算機の速度の変化と，その除き方

同じ計算でも，試行ごとに1エポックあたりの時間が異なった．
- シード0〜2に比べ，シード3・4は全手法で約3〜4%遅い．
- シード4の ASA-SVRG だけは，全ての区間が同じシードの他の手法より約6%速い．全勾配の計算も7.01 s で，他は7.5〜7.6 s である．
- この速さは手法によるものではなく，計算機の状態によるものである．全勾配の計算は，全手法で同じ計算だからである．

そのため，手法間の比は次のように求めた．
- 各試行の time_optimizer を，同じ試行の全勾配の計算の時間で割る．全勾配の計算は，SVRG では `time_svrg_full_grad`，NFG・ASA では `time_diagnostic` である．
- この比は，試行間でほとんど変わらない（変動は約0.3%）．

| 手法 | time_optimizer／全勾配の計算（シード0〜4） | 平均 |
|---|---|---:|
| SVRG | 1.4340，1.4365，1.4357，1.4354，1.4308 | 1.4345 |
| NFG-SVRG | 1.4501，1.4494，1.4493，1.4456，1.4448 | 1.4478 |
| ASA-SVRG | 1.4663，1.4691，1.4661，1.4611，1.4641 | 1.4653 |

単純な平均の比は，シード4の ASA-SVRG の影響を受ける．ASA-SVRG／NFG-SVRG で0.998となり，オーバーヘッドが −24 ms と負になる．このため，論点1・2の答えには，正規化した比を用いる．

## 3. 実験計画5.5節の論点への回答

1. **NFG-SVRG・ASA-SVRG の1エポックの時間は，SVRG から全勾配の計算を除いた時間とほぼ等しいか．**
   - ほぼ等しい．正規化した比は，NFG-SVRG／SVRG が1.009，ASA-SVRG／SVRG が1.022である．
   - 全勾配の計算は，SVRG の1エポックの41.1%を占める．
   - NFG-SVRG と ASA-SVRG は全勾配の計算を省くため，1エポックあたりの時間は SVRG の約0.60倍である．
2. **ASA-SVRG の逐次更新のオーバーヘッド．**
   - NFG-SVRG に対して1.2%である（time_optimizer 約10.7 s に対して約0.13 s／エポック）．
   - NFG-SVRG と ASA-SVRG の違いは，平均パラメータの逐次更新（式(13)）のみである．そのため，この差がオーバーヘッドの大きさである．
3. **SGD との実時間での比較．**
   - 1エポックあたりの時間は，SGD が有利である．SGD は1回の更新で順伝播・逆伝播を1回行うが，SVRG系は2回行う．SGD の time_optimizer は ASA-SVRG の0.556倍である（同じシードの比の中央値，範囲0.549〜0.602）．
   - 精度40%への到達は，SGD の方が早い（511 s 対 661 s）．
   - $ t = 1000 $ s では，テスト精度は同等である（ともに0.450）．
   - 最終のテスト精度は，SGD が0.465（$ t = 1204 $ s），ASA-SVRG が0.457（$ t = 1068 $ s）である．SGD の方が実時間が約13%長い．
   - 学習損失は，全区間で SGD の方が低い．
   - ASA-SVRG の曲線は SGD より滑らかである．シード間の標準誤差も小さい（最終精度で0.0020，SGD は0.0099）．
   - SVRG と NFG-SVRG は，実時間でも ASA-SVRG と SGD を明確に下回る．NFG-SVRG は，ランダム点のスナップショットにより学習が不安定となり，損失が周期的に増加する．
