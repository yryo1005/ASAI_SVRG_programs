# report_025

本レポートは，`.orders/order_025.md` の指示に基づき実施した，実験ex0022（GroupNorm下での
4手法比較，分散削減の効率性検証）の実装内容と結果をまとめたものである．

## 1. 目的

実験2（`.reports/report_022.md`）・ex0021（`.reports/report_023.md`，
`.reports/report_024.md`）を通じて，GroupNormの導入によりNFG SVRG・ASAI SVRGの発散が完全に
解消され，ASAI SVRGがNFG SVRGに対して分類精度で29〜45ポイントの大きな優位性を示すことが
確認された．ただしこれらの実験はNFG SVRG・ASAI SVRGの2手法比較にとどまっており，実験2の
終了基準4（`.reports/report_022.md`）である「分散削減の利点（同一オラクル呼び出し回数での
より高い精度）」は未検証のまま残っていた．

本実験ex0022は，GroupNorm下でSGD・SVRG・NFG SVRG・ASAI SVRGの4手法を比較し，同一のオラクル
呼び出し回数のもとでASAI SVRGが他手法より効率的に学習を進められるかを検証する．さらに，
バッチサイズを512から128, 32へと縮小した場合にもこの優位性が維持されるか（＝提案手法が
ミニバッチサイズの縮小に対して頑健であるか）を確認する．

## 2. 実装着手前に発見した既存実装の食い違い

実装に着手する前に，本実験が複製元とする実験2・ex0021のプログラムを確認したところ，
`.orders/order_025.md` の記述と実装の間に2つの食い違いを発見した．いずれもユーザーに報告し，
対応方針の指示を受けた上で実装している．

### 2.1 SVRG系Optimizerクラスの選択

`.orders/order_022.md`（実験2）・`.orders/order_023.md`（ex0021）はいずれも，比較手法として
`SVRGFinalPoint`／`NFGSVRGFinalPoint`（NFG SVRG原論文Algorithm 1に忠実な，内部ループの
最終パラメータを次のスナップショットとする版）を用いると明記していたが，実際の実装
（`programs/ex002_cifar10_alexnet/train.py`，`programs/ex0021_cifar10_alexnet_norm/train.py`）
は，`SVRG`／`NFGSVRG`（ASAI SVRG論文Algorithm 4の理論解析に合わせ，次のスナップショット点
$ z_{s+1} $ を内部ループのパラメータ列から一様ランダムに選ぶ版）を使用していた．`ex000`・
`ex001` は指示通り `SVRGFinalPoint`／`NFGSVRGFinalPoint` を使用しており，実験2・ex0021のみが
この食い違いを持つ．

ユーザーに確認したところ，実験2・ex0021で実際に使われてきた `SVRG`／`NFGSVRG`（ランダム点
採用版）に本実験でも統一する方針を選択された．これにより，`.orders/order_025.md` 3節が想定
する既存20条件（ex0021のNFG SVRG・ASAI SVRG，バッチサイズ512, 128，学習率0.001）のコピーに
よる再利用が，アルゴリズムの一貫性を保ったまま実現できる．

### 2.2 `elapsed_time` の計上方法

実験2・ex0021の実装は，NFG SVRG・ASAI SVRGについても評価指標（近似誤差）算出のためだけに
毎エポック計算する真のフル勾配（`compute_full_gradient_and_metrics`）の計算時間を，SVRGの
（アルゴリズム自体に必要な）真のフル勾配計算時間と区別せず `elapsed_time` に計上していた．
これは `.orders/order_022.md` 7節「ASAI SVRG・NFG SVRGでは評価指標算出のためだけに計算する
フル勾配のコストを実行時間に含めない」という指示と一致しない．

`.reports/report_022.md`〜`.reports/report_024.md` はいずれも `elapsed_time` を軸とした
考察を行っておらず（オラクル呼び出し回数・エポック数を評価軸として用いている），過去の
結論への影響はない．本実験ではこの点を修正し，`elapsed_time` の累積対象からNFG SVRG・
ASAI SVRGの診断専用フル勾配計算を除外した（`programs/ex0022_cifar10_alexnet_groupnorm/
train.py` の `run_variance_reduced` 関数）．この修正の効果は単体テスト
`test_elapsed_time_excludes_diagnostic_full_gradient_for_nfg_and_asai`
（`tests/test_ex0022_cifar10_alexnet_groupnorm.py`）で確認している．ただし3節で述べる通り，
ex0021からコピーにより再利用する既存20条件の `elapsed_time` は再学習せずそのまま流用する
ため，この修正は反映されていない．

## 3. 実装

### 3.1 ディレクトリ構成とプログラムの再利用

`.orders/order_025.md` 2節の指示に基づき，`programs/ex0022_cifar10_alexnet_groupnorm/` に
`programs/ex0021_cifar10_alexnet_norm/` を複製する形で実装した．

- `model.py`：`ex0021` と完全に同一（`AlexNetCIFARNorm` の正規化層選択肢はそのまま保持し，
  本実験ではGroupNorm固定として使用する）
- `data.py`：`ex0021` と同一の前処理（`EXPERIMENT_NAME` のみ変更）
- `train.py`：新規に実装．比較手法にSGD・SVRG（フル勾配版，`SGD`／`SVRG`クラス）を追加し，
  バッチサイズ・学習率のグリッド（4節）に対応させた．SGDの学習ループは
  `programs/ex002_cifar10_alexnet/train.py` の `run_sgd` を，SVRG系3手法の学習ループは
  同ファイルの `run_variance_reduced`（フル勾配をSVRGのみ実際に使用し，NFG SVRG・ASAI SVRGは
  近似勾配を使用する分岐）を土台とし，GroupNorm固定のモデル（`AlexNetCIFARNorm`）・
  2.2節の`elapsed_time`修正を反映して再構成した．

### 3.2 既存結果の再利用（コピー）

`.orders/order_025.md` 3節の指示に基づき，学習率0.001・GroupNorm・バッチサイズ512, 128の
NFG SVRG・ASAI SVRG，計4セル×5Seed＝20条件を，`outputs/ex0021_cifar10_alexnet_norm/` から
`outputs/ex0022_cifar10_alexnet_groupnorm/` へディレクトリごとコピーして再利用した
（`train.py` の `reuse_ex0021_results` 関数）．

コピーを単純なディレクトリコピーで実現するため，`hp_name` 関数（ハイパーパラメータ条件名の
構築）を，該当4セルにおいてex0021の命名規則と文字列が完全に一致するよう設計した．これにより
コピー時のリネームは不要である（一致することは
`tests/test_ex0022_cifar10_alexnet_groupnorm.py::test_hp_name_matches_ex0021_for_reused_cells`
で確認している）．コピーした `config.json` は，`experiment` フィールドを
`"ex0022_cifar10_alexnet_groupnorm"` に更新し，`reused_from` フィールドにコピー元のパスを
追記した．

### 3.3 初期値の再現性の検証（`.orders/order_025.md` 3節，必須）

コピーによる再利用が妥当であるためには，ex0021とex0022でモデルの初期パラメータおよび
データローダーの初期順序が完全に一致している必要がある．これを次の単体テストで検証した．

- `test_model_initial_parameters_match_ex0021`（Seed 0〜4）：`load_model` が返すモデルの
  全パラメータが，ex0021とex0022で `torch.equal` により完全一致することを確認．
- `test_dataloader_initial_order_matches_ex0021`（Seed×バッチサイズの組み合わせ）：
  `load_dataloader` が返す学習用・検証用データローダーの先頭バッチ（画像・ラベル）が，
  ex0021とex0022で完全一致することを確認．

いずれも全パラメータ・全条件で一致した．`model.py`／`data.py` がex0021と同一のコードで
あることから予想された結果であるが，`.orders/order_025.md` の指示通り明示的に検証した．

## 4. 実験条件

- **正規化層**：GroupNorm固定．`.reports/report_024.md` 6節4項の判断（SpectralNormはASAIの
  優位性自体を消してしまうため不採用．GroupNormがLayerNormよりわずかに優れていたため採用）
  を踏襲する
- **バッチサイズ**：512, 128, 32
- **学習率**：0.01, 0.001
- **比較手法**：SGD, SVRG, NFG SVRG, ASAI SVRG（2節1項参照）の4手法
- **Seed数**：5（0〜4）
- **正則化係数**：$ \lambda=5\times10^{-4} $（既存実験と同一）
- **エポック数**：バッチサイズ512, 128, 32についてそれぞれ48, 12, 3エポック．総イテレーション
  数（epoch×K）がおおむね4700で揃うよう決定した（`.orders/order_025.md` 5節，
  `tests/test_ex0022_cifar10_alexnet_groupnorm.py::test_epochs_by_batch_size_keep_total_iterations_roughly_constant`
  で確認済み）

条件数はバッチサイズ3種×学習率2種×手法4種×Seed5＝120条件．うち20条件（NFG SVRG・
ASAI SVRG×バッチサイズ512, 128×学習率0.001）は3.2節の通りコピーにより再利用し，残り100条件を
新規に学習した．

## 5. 結果

### 5.1 発散の有無と最終・最高分類精度

全120条件（4手法×3バッチサイズ×2学習率×5Seed）についてSeed平均の最終・最高テスト精度と
発散（訓練損失がNaNになった）Seed数を次に示す（詳細は`outputs/ex0022_cifar10_alexnet_groupnorm/
grid_summary.md`）．

| バッチサイズ | 学習率 | SGD | SVRG | NFG SVRG | ASAI SVRG |
|---|---|---|---|---|---|
| 512 | 0.01 | 0.7665 / 0/5 | 0.7616 / 0/5 | 0.1008 / 0/5 | 0.7588 / 0/5 |
| 512 | 0.001 | 0.6242 / 0/5 | 0.6263 / 0/5 | 0.3425 / 0/5 | 0.6348 / 0/5 |
| 128 | 0.01 | 0.7414 / 0/5 | 0.7325 / 0/5 | 0.1098 / 0/5 | **0.1000 / 4/5** |
| 128 | 0.001 | 0.6156 / 0/5 | 0.6173 / 0/5 | 0.2053 / 0/5 | 0.6155 / 0/5 |
| 32 | 0.01 | 0.6782 / 0/5 | 0.7171 / 0/5 | 0.2482 / 0/5 | 0.4146 / 0/5 |
| 32 | 0.001 | 0.5671 / 0/5 | 0.5843 / 0/5 | 0.4322 / 0/5 | 0.5084 / 0/5 |

（各セルは「最終精度 / 発散Seed数」．正規化層なしであった実験2と異なり，SGD・SVRG・
NFG SVRGは全条件で発散が完全に解消されている．ASAI SVRGのみ，バッチサイズ128・学習率0.01
の条件で4/5 Seedが発散した．）

主要な観察は次の3点である．

1. **SGD・SVRGは全条件で安定かつ高精度**：56〜77%の範囲で分類精度に到達し，発散は一切
   生じなかった．実験2で確認された安定性（`report_022.md`）がGroupNorm下でも維持されている．
2. **NFG SVRGは，発散こそしないが，ほぼ全条件で実用上崩壊している**：最終精度は10〜43%
   にとどまり，最高精度（41〜54%）との差が大きい．これは後述5.3節の近似誤差爆発パターンに
   起因する．
3. **ASAI SVRGは条件依存で挙動が大きく異なる**：バッチサイズ512（両学習率）およびバッチ
   サイズ128・学習率0.001では，SGD・SVRGに匹敵する高い精度（61〜76%）に到達する．一方，
   バッチサイズ128・学習率0.01では4/5 Seedが発散し，バッチサイズ32では両学習率で
   SGD・SVRGを下回る（41〜51%）．

### 5.2 オラクル呼び出し回数を横軸とした効率性の比較（`.orders/order_025.md` 7節1項）

本実験の中心的な検証項目である「同一オラクル呼び出し回数のもとでのASAI SVRGの効率性」を，
ASAI SVRGが発散しなかった条件について確認する．1エポックあたりのオラクル呼び出し回数は
SGDが$ N $，NFG SVRG・ASAI SVRGが$ 2N $，SVRGが$ 3N $であり，SVRGはASAI SVRGの1.5倍の
コストを要する．オラクル呼び出し回数を揃えて（線形補間により）分類精度を比較した結果を
以下に示す（$ N $=50000で正規化，`outputs/ex0022_cifar10_alexnet_groupnorm/
accuracy_grid_by_oracle_calls.png`）．

**バッチサイズ512・学習率0.01**（オラクル呼び出し回数 #grad/N＝0, 9.6, 19.2, 28.8, 38.4, 48.0）：

| #grad/N | SGD | SVRG | ASAI SVRG |
|---|---|---|---|
| 9.6 | 0.633 | 0.453 | 0.527 |
| 19.2 | 0.701 | 0.587 | 0.665 |
| 28.8 | 0.698 | 0.632 | 0.718 |
| 38.4 | 0.765 | 0.666 | 0.742 |
| 48.0 | 0.767 | 0.696 | 0.752 |

**バッチサイズ512・学習率0.001**：

| #grad/N | SGD | SVRG | ASAI SVRG |
|---|---|---|---|
| 9.6 | 0.384 | 0.286 | 0.306 |
| 19.2 | 0.481 | 0.337 | 0.366 |
| 28.8 | 0.542 | 0.372 | 0.425 |
| 38.4 | 0.590 | 0.415 | 0.473 |
| 48.0 | 0.624 | 0.445 | 0.512 |

**バッチサイズ128・学習率0.001**：

| #grad/N | SGD | SVRG | ASAI SVRG |
|---|---|---|---|
| 4.8 | 0.466 | 0.308 | 0.302 |
| 9.6 | 0.579 | 0.382 | 0.427 |
| 12.0 | 0.616 | 0.418 | 0.474 |

いずれの条件でも，**ASAI SVRGは同一オラクル呼び出し回数において一貫してSVRGを上回る**
（バッチサイズ512・学習率0.01の48.0Nでは0.752対0.696，同0.001の48.0Nでは0.512対0.445，
バッチサイズ128・学習率0.001の12.0Nでは0.474対0.418）．SGDとの比較では，バッチサイズ512・
学習率0.01でほぼ同水準（0.752対0.767）に達する一方，学習率0.001やバッチサイズ128では
SGDに一定の差をつけられている．

一方，**バッチサイズ32ではこの優位性が失われ，ASAI SVRGはSVRGより同一オラクル呼び出し
回数での精度が低い**（学習率0.01の3.0Nで0.339対0.453，学習率0.001の3.0Nで0.242対0.327）．

### 5.3 近似誤差の挙動とNFG SVRGの崩壊パターンの再現

`.reports/report_023.md` 6.3節で観察された「NFG SVRGが学習後半で近似誤差が急増し精度が
崩壊する」パターンは，本実験の新規条件（特に学習率0.01）でも一貫して確認された．例えば
バッチサイズ512・学習率0.01のNFG SVRG（Seed 0）は，エポック2で31.0%まで学習が進んだ後，
近似誤差が$ 1.2\times10^1 $台に増大し始めるとともに精度が10%（チャンスレベル）まで崩壊し，
以後48エポック終了まで回復しなかった．

**より重要な新規知見として，本実験ではASAI SVRGについても同一の崩壊パターンが観測された**．
バッチサイズ128・学習率0.01のASAI SVRG（Seed 0）の軌跡を示す．

```
epoch:        0     1     2     3     4     5     6    7    ...   12
test_accuracy: 0.101 0.101 0.452 0.545 0.190 0.100 0.100 0.100 ... 0.100
approx_error:  3.7e-01 5.8e-06 8.1e-01 1.9e+01 1.6e+02 7.4e+05 nan  nan ... nan
```

エポック3で54.5%に達した後，エポック4〜5で近似誤差が$ 10^1 $から$ 10^5 $のオーダーへ急増し，
精度がチャンスレベルまで崩壊，5Seed中4Seedで最終的に訓練損失がNaNとなった（残る1Seedも
近似誤差が$ 10^3\sim10^4 $台まで達し，実質的に同様の崩壊を示している）．

この結果は，`.reports/report_024.md` で確認された「近似誤差の爆発とそれに伴う精度崩壊」が
NFG SVRGに特有の現象ではなく，**ASAI SVRGも学習率が大きい・バッチサイズが小さいなど
不安定化しやすい条件下では同じ崩壊ダイナミクスに陥りうる**ことを示している．ASAI SVRGの
優位性は，この崩壊を完全に防止することではなく，崩壊が生じにくい（あるいは崩壊しても
より軽微な）条件範囲がNFG SVRGより広いことに由来すると考えられる．

## 6. 考察

### 6.1 分散削減の効率性の検証（終了基準1）

5.2節の結果は，`.orders/order_025.md` 7節1項が要求する検証に対し，**部分的に肯定的な
結論**を与える．ASAI SVRGが発散しなかった4条件（バッチサイズ512の両学習率，バッチサイズ
128・学習率0.001）では，同一オラクル呼び出し回数のもとでASAI SVRGが一貫してSVRGより高い
精度に到達しており，「フル勾配を計算しない近似がSVRGと同等以上の効率を持つ」という
NFG SVRG原論文・ASAI SVRG論文の主張が，非凸・実践的なCNN設定でも支持された．特に
バッチサイズ512・学習率0.01では，ASAI SVRGはSGD（フル勾配を全く近似しない最も単純な
手法）にほぼ匹敵する精度に達しており，実用上の有効性を示す最も強い証拠と言える．

ただし，この効率性はバッチサイズ32では消失し，むしろSVRGに劣る．これは6.2節で述べる
安定性の問題と表裏一体であり，効率性の主張は無条件には成立しないことに注意が必要である．

### 6.2 バッチサイズ縮小に対する頑健性（終了基準2）

`.orders/order_025.md` 7節2項が注目したバッチサイズ縮小（512→128→32）に対する頑健性は，
**ASAI SVRGについて明確な負の結果**を示した．

- バッチサイズ128・学習率0.01では，4/5 Seedで発散した．これは`report_023.md`・
  `report_024.md`で検証してきた学習率0.001の条件では一貫して発散が解消されていたのに対し，
  学習率を0.01に上げるとGroupNormによる安定化効果だけでは不十分になることを示す．
- バッチサイズ32では，両学習率で発散こそ生じないものの，SGD・SVRGに対する精度の劣位
  （5.2節）に加え，学習率0.01では最終精度（41.5%）が最高精度（57.5%）を大きく下回り
  （5.3節と同種の，完全な崩壊には至らないものの顕著な精度低下），バッチサイズ縮小に
  対する頑健性は限定的であることが分かった．

`report_023.md`・`report_024.md`はいずれも学習率0.001に固定した実験であったため，本実験で
初めて学習率0.01を導入したことで，GroupNormによる安定化がバッチサイズ・学習率の両方に
対して万能ではないことが明らかになった．

### 6.3 学習率0.01と0.001とでの相対的な効率性の変化（終了基準3）

学習率0.01は，ASAI SVRGが安定する条件（バッチサイズ512, 128の一部）では0.001より高い
最終精度をもたらす（例：バッチサイズ512で0.635→0.759）と同時に，不安定化のリスクも
増大させる（バッチサイズ128での発散）．この二面性は，SGD・SVRGでは学習率0.01が一貫して
0.001より高精度をもたらす（表5.1参照）のに対し，SVRG系分散削減手法（NFG SVRG・ASAI SVRG）
では学習率を上げることの恩恵とリスクが拮抗することを示しており，`report_020.md`・
`report_021.md`で確認された「学習率が理論的な安定領域の上界に近いほどNFG SVRG・ASAI SVRGが
不安定化する」傾向が，本実験のような非凸・実践的な設定でも再確認されたと言える．

### 6.4 総合的な結論

以上を総合すると，ASAI SVRGは，(a) 十分に大きいバッチサイズ（本実験では128以上）かつ
(b) 過度に大きくない学習率（バッチサイズ128では0.001）という条件下では，SVRGに対する
明確な効率性の優位性を持ち，SGDにも匹敵しうる実用的な手法であると言える．一方で，
バッチサイズが小さくなる，または学習率が大きくなるにつれて，NFG SVRGと同種の近似誤差
爆発による崩壊のリスクが高まり，効率性の優位性も失われる．したがって，ASAI SVRGの
実用上の優位性は普遍的なものではなく，特定のハイパーパラメータ領域に限定される条件付きの
結果として報告するのが適切である．

## 7. 未解決の論点・今後の検討候補

1. **ASAI SVRGの崩壊条件の境界の特定**：本実験では，バッチサイズ128・学習率0.01が発散し，
   バッチサイズ128・学習率0.001は安定という急激な変化が観察された．学習率0.001〜0.01の
   間（例えば0.003, 0.005）を追加で探索し，崩壊が生じる境界がどこにあるか，またその境界が
   バッチサイズにどう依存するかを特定することは，ASAI SVRGの適用可能な条件を明確化する
   上で有用である．
2. **バッチサイズ32での劣位の原因**：バッチサイズ32でASAI SVRGがSVRGに劣る原因（近似誤差の
   蓄積が内部ループ長 $ K $ の増大とともに悪化するためか，学習率とバッチサイズの相互作用に
   よるものか）は本実験のデータだけでは特定できない．近似誤差の時系列軌跡をバッチサイズ
   ごとに詳細に比較する追加分析が必要である．
3. **`.reports/report_024.md`で得られたGroupNorm下の安定性が学習率に依存する点の一般化**：
   `report_023.md`・`report_024.md`はいずれも学習率0.001固定の実験であったため，
   GroupNormの安定化効果の学習率依存性はこれまで検証されていなかった．本実験は学習率0.01
   でこの効果が部分的に失われることを示したが，これがGroupNorm固有の限界か，正規化層一般に
   共通する限界かは，LayerNorm・SpectralNormを学習率0.01で追加検証することで切り分けられる．
4. **勾配クリッピング等の追加安定化手法の要否**：ASAI SVRGの崩壊時（5.3節）は近似誤差が
   短期間で数桁増大するパターンを示しており，勾配クリッピングやスナップショット更新の
   減衰（学習率のウォームアップ等）といった追加の安定化手法が崩壊を防止できるかは，
   今後の検討候補である．
5. **2.1節・2.2節で報告した実験2・ex0021の実装上の食い違いへの対応**：本実験ではユーザーの
   判断により実装済みの`SVRG`／`NFGSVRG`（ランダム点採用版）に統一したが，`.orders/
   order_022.md`・`.orders/order_023.md`が本来意図していた`SVRGFinalPoint`／
   `NFGSVRGFinalPoint`（NFG SVRG原論文Algorithm 1準拠）による追試験は未実施のままである．
   両者の挙動の違い（次エポックのスナップショット点をランダムに選ぶか，内部ループの最終点を
   採用するか）が，本実験で観察された崩壊パターンの発生条件にどう影響するかは，論文の
   主張の頑健性を確認する上で検討に値する．
