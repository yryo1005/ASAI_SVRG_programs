# report_073：E5 エポック内の平均点で評価した SGD（実験計画8章）

## 0. 要点

- SGD を1回の学習の中で，最終点 $ {\mathbf w}^{K} $ とエポック内の平均点 $ \bar{\mathbf w} = \frac{1}{K}\sum_{k=0}^{K-1}{\mathbf w}^{k} $ の両方で評価した．
  - 平均点の添字と式は ASA-SVRG の `running_avg_params` と同じである（テストでビット単位の一致を確認した）．
  - 学習の軌跡は変えていない．最終点の記録は，全15試行・全評価点で既存の SGD のログと完全に一致した（2節）．
- 優先度1・2と優先度3の CIFAR-10・512 の15試行は完了した．ImageWoof・512（1000エポック）は実行中である（5節）．
- 結果（3節）：
  - **SGD（平均点）の揺らぎは，全ての設定で ASA-SVRG と同程度以下である．** ImageWoof・128 では 0.21 ± 0.01 と 0.20 ± 0.01（間隔2）で同程度，CIFAR-10 では SGD（平均点）の方が小さい．
  - **SGD（平均点）の予算での精度は，全ての設定で ASA-SVRG より明確に高い．** 特に ImageWoof・128 では，平均点で評価すると精度が 46.54% から 51.43% に上がり，ASA-SVRG（45.81%）を約5.6%pt 上回る．
  - 実験計画8.6節の判断の目安では，完了した3設定はいずれも **目安3** に当たる．目安1（4.4節の主張は評価点をそろえても成り立つ）に当たる設定はない．
- したがって，表IVの揺らぎの差は主に評価点（平均点で評価したこと）による．4.4節の主張の表現と回答書での扱いは，指導教員との相談が必要である（6節）．

### 1.1 平均点の評価で学習の軌跡を変えないための実装

- 平均への加算は，逆伝播の後，更新の前に行う．パラメータと勾配は変えない．
- 最終点の評価は，既存の SGD と同じく，シャッフルする学習用のローダーで行う．既存の実装と同じ順序でシャッフルの乱数を消費する．
- 平均点の評価は，別のモデル（`copy.deepcopy`），シャッフルしない学習データのローダー，`torch.random.fork_rng` の中で行う．
- $ s = 0 $ の平均点の記録は，初期パラメータ（最終点と同じ）の値とした．

## 3. 結果

値は5シードの平均 ± 標準誤差（ddof=0）である．揺らぎは表IVと同じ定義である．$ \#\mathrm{grad}/N $ が予算の1/2以上・予算以下の区間で，隣り合う評価点の間のテスト精度の変化 $ |a_{s} - a_{s-1}| $ の平均をとる．

- 評価点の間隔は SGD が1，ASA-SVRG が2である．
- SGD は1エポックおきに間引いて，間隔を2にそろえた値も示す．
- ASA-SVRG の値は，表IVの元の既存ログ（ex0024，ex0051）から計算した．

### 3.1 揺らぎと予算での精度

| | SGD（平均点） | 0.19 ± 0.01 | **0.21 ± 0.01** | **51.43 ± 0.18** | 3.0029 ± 0.0048 |
| | ASA-SVRG | — | **0.20 ± 0.01** | **45.81 ± 0.20** | 3.3843 ± 0.0043 |
| CIFAR-10・128（90） | SGD（最終点） | 0.34 ± 0.02 | 0.32 ± 0.03 | 76.24 ± 0.09 | 0.2332 ± 0.0000 |
| | SGD（平均点） | 0.05 ± 0.00 | **0.06 ± 0.00** | **76.25 ± 0.11** | 0.2332 ± 0.0000 |
| | ASA-SVRG | — | **0.22 ± 0.00** | **75.20 ± 0.15** | 0.3894 ± 0.0019 |
| CIFAR-10・512（350） | SGD（最終点） | 0.20 ± 0.01 | 0.19 ± 0.02 | 75.81 ± 0.07 | 0.2334 ± 0.0000 |
| | SGD（平均点） | 0.04 ± 0.00 | **0.04 ± 0.00** | **75.76 ± 0.07** | 0.2334 ± 0.0001 |

| | ASA-SVRG | — | 0.19 ± 0.01 | 48.71 ± 0.19 | 3.2464 ± 0.0045 |
| | SGD（表IVの既存ログ） | 2.53 ± 0.03 | 2.51 ± 0.06 | 45.40 ± 1.81 | 2.9309 ± 0.0861 |

- CIFAR-10 の SGD の学習損失は，シードの間でほぼ同じ値（標準誤差が小数第4位で0）である．既存ログ ex0024 でも同じであり，E5 の実装によるものではない．
- ImageWoof・128 の SGD（平均点）の学習損失は，最終点より小さい（3.0029 と 3.1407）．

### 3.2 同じシードの差（SGD（平均点）− SGD（最終点））

| 設定 | 揺らぎ（間隔1）の差［%pt］ | 揺らぎ（間隔2）の差［%pt］ | 精度の差［%pt］ | 学習損失の差 |
|---|---:|---:|---:|---:|
| ImageWoof・128 | −2.86 ± 0.15 | −2.56 ± 0.09 | +4.89 ± 0.87 | −0.1378 ± 0.0226 |
| CIFAR-10・128 | −0.29 ± 0.02 | −0.26 ± 0.03 | +0.01 ± 0.02 | −0.0001 ± 0.0000 |
| CIFAR-10・512 | −0.16 ± 0.01 | −0.14 ± 0.02 | −0.04 ± 0.02 | −0.0000 ± 0.0000 |

- 平均点で評価すると，全ての設定で揺らぎが大きく減る．ImageWoof・128 では約1/15になる．
- 精度は，ImageWoof・128 では上がり，CIFAR-10 ではほぼ変わらない．
  - CIFAR-10 では，SGD は予算の後半にほぼ収束しており，最終点と平均点の差が小さい．
  - CIFAR-10 の SGD は，最終点でも ASA-SVRG より精度が高い（表IVと同じ）．

### 3.3 実験計画8.6節の判断の目安に照らした判定

判定は，SGD（平均点，間隔2）と ASA-SVRG の平均 ± 標準誤差の区間が重なるかどうかで行った．

| 設定 | 揺らぎ：SGD（平均点）と ASA-SVRG | 精度：SGD（平均点）と ASA-SVRG | 当たる目安 |
|---|---|---|---|
| ImageWoof・128 | 同程度（区間が重なる） | SGD（平均点）が明確に高い（+5.6%pt） | 目安3 |
| CIFAR-10・128 | SGD（平均点）が明確に小さい | SGD（平均点）が明確に高い（+1.1%pt） | 目安3 |
| CIFAR-10・512 | SGD（平均点）が明確に小さい | SGD（平均点）が明確に高い（+0.7%pt） | 目安3 |
| ImageWoof・512 | 実行中 | 実行中 | 未判定 |

- 目安1（SGD（平均点）の揺らぎが ASA-SVRG より明確に大きい）に当たる設定はない．
- 4.4節の「ASA-SVRG は SGD より揺らぎが小さい」という主張は，評価点をそろえると成り立たない．
- 8.6節では，目安3の場合は目安2と同じ対応をとる．すなわち，主張の表現を指導教員と相談して改め，回答書で結果を隠さずに扱いを説明する．
