## 2. 指示の解釈

- `実験指示E10.md`（E10：付録B.1 の a9a の BCE を，独立一様サンプリング（`uniform_with_replacement`）で実行する）を本PCで実施する．
  - 番号は指示書0.3節のとおり `order_082`／`report_082`，`ex015_e10_a9a_bce_uniform` とする（E9 は `order_081` で実施中．`order_082`・`report_082` は未使用であることを確認した）．
- 「CPUで実行できるので並列で実施」は，実行中の E9（GPU，`ex005` の ASA-SVRG（reset）・バッチサイズ512 のシード1〜4，4並列）と E10（CPU）を同時に実行すること，および E10 の20試行をマルチプロセスで並列に実行することと解釈する．
  - E10 の並列数は，指示書3.2節に従い，1試行の DRAM の使用量と論理コア数から，E9 の4プロセスが使う CPU コアとメモリを差し引いて決める．
  - E9 は精度の実験であり実時間を計測しないため，同時に実行しても E9 の結果は変わらない．E10 の `elapsed_time` も結論には用いない．
- 手順は指示書のとおり，(1) `ex014` の `data.py`・`model.py`・`train.py` のコピーと `train.py` の変更（サンプリング方式の選択，保存先，引数），`README.md`，`compare_e10.py`，(2) 一致の確認（(a) random reshuffling で E4・E8 とビット単位で一致，(b) 一様サンプリングの動作），(3) 本実行（20試行），(4) `analysis_e10.py` と `tests/test_e10_programs.py`，(5) 集計（`e10_summary.md`），(6) `report_082.md` と `E10_results.zip`，とする．
- 新規作成は指示書0.3節のファイルのみとする．既存のファイル（`ex014`・`ex008`・`ex006`・`common/` のプログラム，既存の結果，`document.md`，既存のテスト等）は変更しない．git の commit・push は行わない．
