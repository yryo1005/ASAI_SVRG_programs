# 実験ex0023：GroupNorm・学習率0.001固定での長期エポック学習（誤差床の収束観察）

## 1. 目的

ex0022（`report_025.md`）は，GroupNorm下でSGD・SVRG・NFG SVRG・ASAI SVRGの4手法を比較し，
学習率0.001では全条件で発散が生じず，ASAI SVRGが同一オラクル呼び出し回数のもとでSVRGを
一貫して上回ることを示した（5.2節）．一方，学習率0.01ではASAI SVRGがバッチサイズ128で
4/5 Seed発散するなど，学習率を上げることの恩恵とリスクが拮抗する結果となった（6.2節，
6.3節）．

本実験ex0023は，**学習率0.01の条件を対象から外し**，最も安定した挙動が確認されている
学習率0.001に絞った上で，**エポック数を大幅に延長し，近似誤差 $\|e_s\|^2$ および分類精度が
プラトーに達するまで観察する**．これにより，実験1（`report_021.md`）で確認された
「誤差床はtransientであり，十分なエポック数の下ではSVRGと同水準まで収束しうる」という
強凸設定での知見が，非凸・実践的なCNN設定（GroupNorm下）でも成立するか，あるいは非凸性
ゆえに恒久的な誤差床が観察されるかを検証する．

学習率0.01の結果はex0022（`report_025.md`）で既に取得済みであり，本実験で再検証する
必要はない．本実験のレポートでは，学習率0.01の結果（崩壊が生じやすい）と対比する形で，
学習率0.001における長期的な収束挙動を報告すること．

## 2. ディレクトリ構成とプログラムの再利用

`programs/ex0023_cifar10_alexnet_groupnorm_longrun/` に，`programs/
ex0022_cifar10_alexnet_groupnorm/` を複製する形で実装する．モデル定義・データ処理は
変更不要であるためそのままコピーし，`train.py` はエポック数・学習率のグリッド（4節）に
合わせて変更する．出力先は `outputs/ex0023_cifar10_alexnet_groupnorm_longrun/` とする．

## 3. 既存結果の再利用について（再利用しない）

ex0022で取得済みの学習率0.001・バッチサイズ512, 128, 32の結果は，**モデルの最終重みは
保存されているが，各Optimizer（特にNFG SVRG・ASAI SVRGの平均勾配・平均パラメータの
running average，SVRGのスナップショット状態等）の内部変数までは保存されていない**ため，
これらの内部状態から学習を再開することはできない．

したがって，本実験は**全条件をゼロから再学習する**．ex0022の該当条件（学習率0.001）の
エポック数がそのまま本実験の延長対象のエポック数に含まれる形になるため，計算コストの
重複が生じる点は許容する．

## 4. 実験条件

- **正規化層**：GroupNorm固定（ex0022と同一）
- **バッチサイズ**：512, 128, 32
- **学習率**：0.001のみ（0.01は対象外とする．2節参照）
- **比較手法**：SGD, SVRG, NFG SVRG, ASAI SVRG（ex0022で用いた実装
  （`SVRG`／`NFGSVRG`，次のスナップショット点を内部ループのパラメータ列からランダムに
  選ぶ版）をそのまま用いる．`report_025.md` 2.1節で報告された食い違いはex0022の時点で
  ユーザーの判断により解消済みであり，本実験でも同じ実装を踏襲する）
- **Seed数**：5（0〜4）
- **正則化係数**：$\lambda=5\times10^{-4}$（既存実験と同一）
- **`elapsed_time`の計上方法**：ex0022の修正（`report_025.md` 2.2節，NFG SVRG・ASAI SVRGの
  診断専用フル勾配計算をelapsed_timeから除外する）をそのまま踏襲する

条件数はバッチサイズ3種×手法4種×Seed5 = 60条件．

## 5. エポック数の決定

エポック数は目安として**200エポック相当の総イテレーション数**を基準とする．ex0022
（`report_025.md` 4節）のエポック数（バッチサイズ512, 128, 32でそれぞれ48, 12, 3エポック，
総イテレーション数約4700）を約4倍に延長し，次を初期値とする．

| バッチサイズ | $K$ | エポック数（目安） | 総イテレーション数 |
| ---: | ---: | ---: | ---: |
| 512 | 98 | 192 | 18816 |
| 128 | 391 | 48 | 18768 |
| 32 | 1563 | 12 | 18756 |

ただし，これはあくまで目安である．学習の途中経過（近似誤差・分類精度の推移）を確認し，

- **200エポック相当の時点でまだ近似誤差・分類精度が明確な傾向で変化し続けている場合**：
  プラトーに達したと判断できるまでエポック数をさらに延長すること
- **200エポック相当よりずっと早い段階で既にプラトーに達している場合**：計算コスト削減のため
  早期終了してよい（ただし，実験1のように「一見収束したように見えて実は緩やかに動き続けて
  いる」可能性があるため，プラトーの判断は近似誤差の変化率が十分小さくなったことを数値的に
  確認した上で行うこと）

最終的に採用したエポック数と，プラトー判定の根拠をレポートに明記すること．

## 6. 崩壊への対処方針

ex0022の結果（`report_025.md` 5.3節）では，学習率0.01においてASAI SVRG・NFG SVRGの近似
誤差が短期間で急増し，訓練損失がNaNに至る崩壊パターンが観察された．学習率0.001では
ex0022の範囲（最大48エポック）で崩壊は観察されていないが，**エポック数を大幅に延長する
本実験では，これまで観察されていなかった長期的な崩壊が新たに生じる可能性がある**．

崩壊が生じた場合，これを異常として扱うのではなく，**「学習率0.001でも十分なエポック数の
下では崩壊が生じうるか」という本実験にとって重要な観察結果**として記録し，発生した
エポック数・条件（バッチサイズ・手法・Seed）を詳細にレポートすること．崩壊が生じた場合の
エポック数延長の打ち切り判断も，レポートに明記すること．

## 7. 実験終了の基準

以下を確認した時点で本実験を完了とする．

1. **近似誤差のプラトー到達**：NFG SVRG・ASAI SVRGの近似誤差 $\|e_s\|^2$ が，各バッチ
   サイズにおいて明確なプラトー（変化率が十分小さくなった状態）に到達すること，または
   6節の基準に従い崩壊が観察されそれ以上の学習が無意味と判断されること
2. **恒久的誤差床 vs transientな誤差床の判定**：実験1（`report_021.md` 6.3節）の知見
   （強凸設定では誤差床はtransientであった）と対比し，本実験の非凸設定において，
   ASAI SVRG・NFG SVRGが最終的にSVRG・SGDと同水準の分類精度・目的関数値に到達するか
   （transient），それとも一定の水準で頭打ちになるか（恒久的な誤差床）を判定すること
3. **ASAI SVRGとNFG SVRGの誤差床の大小関係（定理2の長期的検証）**：プラトー到達後の
   近似誤差・分類精度について，ASAI SVRGがNFG SVRGを一貫して上回るかを確認すること．
   ex0022の短期的な結果（5.2節，5.3節）がエポック数を延長しても維持されるかを検証する
4. **バッチサイズ32における劣位の解消可能性**：ex0022でASAI SVRGがSVRGに劣っていた
   バッチサイズ32・学習率0.001の条件（`report_025.md` 5.2節，7節2項）について，エポック数
   を延長した場合にこの劣位が解消される（追いつく）か，恒久的に残るかを確認すること
