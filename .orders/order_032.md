# 実験レポートの実験系列ごとの分割

## ユーザーからの指示

ex000，ex001等，これまでに実施した実験をまとめたレポートを，実験ごとにファイルを分けて作成する．
この際，ex0021はex002系の実験であるため，ex002と同じレポートにまとめる．

## 指示の解釈と作業方針

- これまでの `.orders/order_{n:03}.md`／`.reports/report_{n:03}.md`（`n = 001` 〜 `031`）は，
  実験の実施順に指示と結果が記録されているが，1つのファイルに複数の実験や複数回の追加検証が
  混在しており，実験系列ごとの経緯・結論を把握しにくい．
- そこで，`programs/` 以下の実験ディレクトリの系列に対応させ，実験系列ごとに独立したレポート
  ファイルを新規に作成する．グループ分けは，実験ディレクトリ名の番号系列（`ex00X` の `X`）に
  従い，以下の5系列とする．
  1. ex000（a9a最小二乗回帰）
  2. ex001（Mushroomロジスティック回帰）
  3. ex002系（ex002：CIFAR-10 AlexNet基本実験，ex0021：正規化層・バッチサイズ変更，
     ex0022：GroupNorm下での4手法比較，ex0023：GroupNorm・長期エポック学習）
  4. ex003系（ex003：Tiny Shakespeareを用いたTransformer，ex0031：同・長期学習）
  5. ex004系（ex004：WikiText-2を用いたTransformer，ex0041：正則化修正後の再実行）
- 各レポートは，`@.ai/ai-dev-kit/documentation.md` の `report.md` に関する規約に従い，実際に
  保存されている学習ログ（`outputs/` 以下）および可視化結果を参照して，実験条件・結果・考察を
  記述する．推測に基づく結果は記述しない．
- 本指示自体は新規のプログラム実装を伴わないため，`report_032.md` という単一の通し番号ファイル
  ではなく，実験系列ごとに識別可能なファイル名（`report_032_ex000.md` 等）で
  `.reports/` 以下に作成する．
