## 2. 指示の解釈

- `実験指示E7.md`（E7：ImageWoof における最終点のスナップショットの SVRG・NFG-SVRG）を本PCで実施する．
  - 本PCは E3（`ex009`）を計測した PC である（GPU：NVIDIA RTX PRO 6000 Blackwell Max-Q Workstation Edition，CPU：Intel Xeon w7-3565X，WSL2）．したがって A・B・C の全てを本PCで実施する．
  - 番号は指示書0.3節のとおり `order_075`／`report_075`，`ex012`，`ex013` を使う（別のPCの E6 に予約した `order_080`・`ex011` とは衝突しない）．
- 「時間計測を要する手法から優先」は，実時間の計測（B：バッチサイズ128の10試行，C：1エポックの時間の短い計測16試行）を精度の実験（A：30試行）より先に行うことと解釈する．
  - 実行の順序は，B・C のプログラムとテストの作成 → 計測環境の確認（3.2節）→ B の本計測 → C の計測 → A の一致の確認 → A の本実行 とする．
  - 指示書0.5節が推奨する順序（A → B → C）とは異なるが，B・C の実行中に他の GPU のジョブを止めるという規則は守る．A のプログラムの作成（GPU を使わない作業）は B・C の実行中に行い，A のテストと GPU を使う確認は B・C の終了後に行う．
- 指示書0.4節に従い，新規作成は0.3節のファイルのみとし，既存のファイルは変更しない．git の commit・push は行わない．成果物は `E7_results.zip` にまとめる．
- `programs_review/document.md` は変更してはいけないファイルに含まれるため，転記すべき内容をレポートの「統合時の注意」に書く．
