# 実験4b（ex0041）：正則化修正後のStage A再実行

## 1. 目的

実験4 Stage A（`report_030.md`）は，WikiText-2・Decoder-only Transformerという設定で
NFG SVRG・ASAI SVRGの安定性を検証したが，8.3節で重大な問題が判明した．正則化係数
$\lambda=5\times10^{-4}$は，実験2・実験3から変更せず踏襲したものであるが，本実験の
語彙サイズ（約33,000，実験3の約512倍）に伴いToken Embedding層のパラメータ数が
大幅に増加した結果，**訓練損失の値が実質的にL2正則化項（特にEmbedding層の初期化
ノルムに起因する項）に支配されており，カテゴリカルクロスエントロピー損失の寄与が
ごく僅かで視認できない**状態になっていた．

この問題は，Stage Aで得られた近似誤差の絶対水準の比較（`report_030.md` 8.4節）や，
バッチサイズ128・学習率0.001での異常な近似誤差増大（同8.4節，未解決論点2）の解釈を
不確実にしており，**正則化が支配的でない状態で得られた測定値でなければ，分散削減
手法の効果を正しく評価できない**．

本実験ex0041は，正則化項が損失を支配しないよう修正した上で，実験4 Stage Aと同一の
グリッドを再実行し，(1) 修正が意図通り機能しているかを検証すること，(2) 修正後の
グリッドで発散・崩壊の有無を改めて確認すること，(3) 修正前後で近似誤差の絶対水準や
学習の進み方がどう変化するかを比較することを目的とする．

（`report_030.md`）で得られた運用上の教訓（5.3節，VRAM実測は最悪ケースのバッチサイズで
行うこと）を本実験でも遵守すること．

## 3. 正則化項が損失を支配する問題への対処

### 3.1 修正方針

`report_030.md` 10節1項で提案された2つの対処方針のうち，**Embedding初期化スケールの
修正（方針(b)）を採用する**．正則化係数 $\lambda$ 自体は実験2・実験3と同一の
$5\times10^{-4}$を維持し，変更しない．理由は次の通り．

- $\lambda$を変更すると，実験2・実験3との手法間比較の一貫性（同一の正則化係数を用いる
  ことで相対比較の条件を揃えるというこれまでの方針）が崩れる
- Token Embedding層のデフォルト初期化（PyTorchの`nn.Embedding`標準初期化，
  $\mathcal N(0,1)$，標準偏差1）は，Transformerの実装として一般的に用いられる
  スケール（例えば $\mathcal N(0, 1/\sqrt{d})$，$d$は隠れ次元）と比べて明らかに
  過大であり，これは実験4に固有の実装上の見落としとして修正するのが適切である

### 3.2 具体的な修正内容

`programs/ex0041_wikitext2_transformer_fixedreg/model.py`にて，Token Embedding層・
出力射影層（`head`）の初期化を，隠れ次元に応じてスケールする方式
（例：$\mathcal N(0, 1/\sqrt{d})$，$d$は隠れ次元）に変更すること．出力射影層についても
同様に，過大な初期ノルムを持たないことを確認すること．具体的な初期化方式・スケール
係数は実装時に妥当なものを選定し，選定根拠（一般的なTransformer実装での慣例等）を
レポートに明記すること．

### 3.3 修正の検証（必須）

学習を開始する前に，修正後のモデルの初期状態について，以下を数値的に確認し，
レポートに明記すること．

1. **初期状態でのL2正則化項の値** $\frac\lambda2\|w\|^2$
2. **チャンスレベルでの交差エントロピー損失の理論値** $\ln(33{,}277)\approx10.4$

正則化項の値が交差エントロピー損失の理論値と比べて同程度かそれ以下（少なくとも
一桁以上大きくない）であることを確認してから，4節以降の学習を開始すること．この
条件を満たさない場合，初期化スケールをさらに調整すること．

## 4. モデル・データセットのその他の設定

実験4 Stage A（`report_030.md` 3節・4節）と同一とする．

- **アーキテクチャ**：Decoder-only Transformer，4層，隠れ次元128，Attention head数4，
  Feed Forward中間次元512，系列長 $T=64$
- **正規化**：LayerNorm
- **目的関数**：カテゴリカルクロスエントロピー損失（次単語予測）+ L2正則化
  （$\lambda=5\times10^{-4}$，3.1節参照）
- **データセット**：WikiText-2，語彙サイズ33,277，$N_{\text{train}}=31{,}567$，
  $N_{\text{test}}=3{,}290$

## 5. 比較手法とOptimizerクラス

実験4と同一．`SVRG`／`NFGSVRG`（次のスナップショット点を内部ループのパラメータ列から
ランダムに選ぶ版）をそのまま用いる．`programs/optimizers/`の各Optimizerクラスは
変更しない．

## 6. 実験条件

実験4 Stage A（`report_030.md` 7節）と同一のグリッドを用いる．

- **比較手法**：NFG SVRG，ASAI SVRG の2手法のみ
- **バッチサイズ**：512, 128, 32
- **学習率**：0.01, 0.001
- **エポック数**：12
- **Seed数**：3（0〜2）

条件数は2手法×3バッチサイズ×2学習率×3Seed = 36条件．

## 7. VRAM実測・並列数の決定（運用上の教訓の反映）

`report_030.md` 5.3節の教訓に基づき，VRAM使用量の実測は**最大バッチサイズ（512）で
実施する**こと．実験4で判明した通り，出力層のロジットテンソルのサイズはバッチサイズに
比例して増加するため，最小バッチサイズでの実測は最悪ケースを representしない．実測結果
に基づき，8プロセス並列時の合計VRAM使用量がGPU総VRAMを超えないよう並列数を決定すること．

## 8. 実験終了の基準

以下を確認した時点で本実験を完了とする．

1. 3.3節の検証により，正則化項が損失を支配していないことを学習開始前に確認できること
2. 全36条件が完了し，発散（NaN）・チャンスレベル張り付き・その他の異常な挙動の有無を
   確認すること
3. 実験4 Stage A（修正前）との比較：
   - 訓練損失の絶対値が，修正前（969〜1080）と比べて交差エントロピー損失を反映する
     妥当な値になっているか
   - バッチサイズ512・学習率0.001の条件（修正前は学習不足と判定，`report_030.md` 8.2節）
     が，修正後は学習の進み方が変化するか
   - 近似誤差 $\|e_s\|^2$ の絶対水準が修正前とどう変化するか，特にバッチサイズ128・
     学習率0.001で観察された異常な増大（`report_030.md` 8.4節，未解決論点2）が
     修正後も再現するかを確認すること
4. 修正後の結果を踏まえ，Stage B（SGD・SVRGを含む本比較）に進む上での実験条件案を
   提案すること
