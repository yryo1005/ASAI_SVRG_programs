## 実験一覧と目的

本実装は，ASAI SVRGおよび比較手法（SGD, SVRG, NFG SVRG, ASAI SVRG）の収束性・実用性を検証するための実験群である。各実験は独立した問題設定を持ち，それぞれ異なる観点から手法を評価する。

### 実験0（補足）：a9aデータセットの二値分類問題

**目的**：NFG SVRG原論文（Medyakov et al., 2025）の非凸実験設定を再現し，本実装（SVRG, NFG SVRG）が先行研究の挙動を正しく再現できることを確認する。これは新規性の主張ではなく，後続の実験1〜3で使用する実装の妥当性を担保するための検証実験である。

- **データセット**：a9a（LIBSVMデータセット，二値分類）
- **モデル**：ロジスティック回帰モデル
- **目的関数**：シグモイド出力に対する二乗和誤差（非線形最小二乗誤差，非凸）
  $$f(x) = \frac{1}{n}\sum_{i=1}^n (y_i - h_i)^2, \quad h_i = \sigma(A_i x)$$
- **バッチサイズ**：1（オンライン学習）
- **学習率**：データから推定したリプシッツ定数 $L$ に基づき解析的に決定（$\eta \le 1/(3L)$ 等）。チューニングは行わない（本題ではないため）
- **正則化**：なし（原論文の設定に合わせる）
- **比較手法**：SGD, SVRG, NFG SVRG，ASAI SVRG

### 実験1：Mushroomデータセットを用いた二値分類問題

**目的**：理論解析（Assumption 1–4：L-平滑性，凸性，µ-強凸性，分散の一様有界性）を満たす設定において，SVRG，NFG SVRG，ASAI SVRGの収束挙動を比較する。特に，定理1（収束特性）・定理2（誤差床の上界比較）の理論的主張が実測でも成立するかを検証する。

- **データセット**：Mushroom（UCI，二値分類）
- **モデル**：ロジスティック回帰モデル
- **目的関数**：二値交差エントロピー損失 + L2正則化（強凸・平滑）
  $$f(w) = \frac{1}{N}\sum_{n=1}^N \ell_{BCE}(y_n, \hat{y}_n(w)) + \frac{\lambda}{2}\|w\|^2$$
- **バッチサイズ**：1（オンライン学習，理論解析の設定と一致）
- **学習率 $\eta$，正則化係数 $\lambda$**：データから推定したリプシッツ定数 $L$ に基づき解析的に決定
- **比較手法**：SGD, SVRG, NFG SVRG, ASAI SVRG

### 実験2：CIFAR-10を用いた多値分類問題

**目的**：理論解析の仮定（平滑性・凸性）を満たさない非凸かつ実践的な設定において，提案手法ASAI SVRGの実用的な有効性を検証する。SVRG系手法はフル勾配計算の性質上，推論結果が確率的に変動する層（Dropout, BatchNormalization等）と理論的に非両立であるため，これらを除去した決定論的なモデルを用いる。

- **データセット**：CIFAR-10（画像10クラス分類）
- **モデル**：AlexNet（CIFAR向けに縮小した構成）。Dropout・BatchNormalizationを除去し，正則化はL2 weight decayに置き換えた決定論的モデル
- **目的関数**：多値交差エントロピー損失 + L2正則化
- **バッチサイズ**：8, 32, 128（グリッド）
- **学習率**：0.01, 0.001, 0.0001（グリッド）
- **内ループ長**：$K = \lceil N/\text{batch size} \rceil$（1エポック相当）
- **比較手法**：SGD, SVRG, NFG SVRG, ASAI SVRG

### 実験3：Tiny Shakespeareを用いた文章生成問題

**目的**：SVRG系分散削減手法が，画像・構造化データだけでなく系列データ（自然言語）にも適用可能であることを示す。近年主流のTransformerアーキテクチャを対象とし，非凸・大規模かつ実用的な設定における提案手法の有効性を検証する。実験2と同様の理由から，Dropout・BatchNormalizationを除去した決定論的なモデルを用いる。

- **データセット**：Tiny Shakespeare（文字レベル言語モデリング）
- **モデル**：Transformer系（Decoder-only，小規模）。Dropoutを除去し，正規化層はLayerNorm（サンプル単位で正規化されるため決定論的）を使用。L2 weight decayで正則化
- **目的関数**：カテゴリカルクロスエントロピー損失（次文字予測） + L2正則化
- **バッチサイズ**：64, 128, 256（グリッド）
- **学習率**：0.01, 0.001, 0.0001（グリッド）
- **内ループ長**：$K = \lceil N/\text{batch size} \rceil$（1エポック相当，$N$は系列チャンク総数）
- **比較手法**：SGD, SVRG, NFG SVRG, ASAI SVRG

### 共通の評価指標

**横軸**
1. 勾配計算回数（オラクル呼び出し回数）
2. エポック数
3. 実行時間（wall-clock time）※ASAI SVRG・NFG SVRGでは評価指標算出のためだけに計算するフル勾配のコストを実行時間に含めない

**縦軸**
1. 目的関数の値（解析解・L-BFGS等で最良値 $f(w^*)$ が得られる場合は差分 $f(z_s)-f(w^*)$，それ以外は目的関数値そのもの）
2. 分類精度（実験0〜2）／次文字予測精度（実験3，補助指標）
3. フル勾配の近似誤差 $\|e_s\|^2$
4. フル勾配のノルム $\|\nabla f(z_s)\|^2$
5. Perplexity（実験3のみ）
6. **各エポックにおける生成サンプルの記録**（実験3のみ）：固定のprompt（開始文字列）から各手法・各エポック時点で生成したテキストをログとして保存し，定性評価および論文中の生成例掲載に用いる
7. **Distinct-n**（実験3のみ）：生成テキストのn-gramユニーク率（例：n=1,2,3）。多様性の指標として記録
8. **Repetition rate**（実験3のみ）：生成テキスト中の同一フレーズ・文字列の繰り返し頻度。学習不足や崩壊生成の検出に用いる

### 共通の実行条件

- 各条件につきSeed数5回で実行し，平均と分散（標準偏差）を記録する
- 内ループ長 $K$ は実験ごとに上記の通り定義する
- 学習率・バッチサイズ等のハイパーパラメータチューニングは実験2・3のグリッド範囲内にとどめ，それ以上の探索は行わない（本論文の主題は手法比較であり，個々の実験でのSOTA精度追求ではないため）
- 収束の桁数や停止条件（何エポック回すか）は妥当に定めてください．ASAIはNFGと比べ誤差床が小さいことがアピールポイントなので，ある程度収束するまでエポックを増やすべきです


### グリッド探索の優先順位

実験2・3のグリッド（学習率・バッチサイズの組み合わせ）を実行する際は，**提案手法ASAI SVRGが他手法（特にNFG SVRG）に対して優位性を示しやすい条件を優先的に探索・実行する**。具体的には以下の観点を優先する。

- 近似誤差 $\|e_s\|^2$ の差（ASAI < NFG）が大きく現れる学習率・バッチサイズの組み合わせ
- 目的関数値・Perplexityの収束曲線において，ASAI SVRGとNFG SVRGの差が視覚的に明確な条件
- 全手法が発散・不安定化せず，かつ手法間の差が最も観察しやすい範囲（学習率が大きすぎて全手法が発散する，または小さすぎて差が出ないという両極端は避ける）

ただし，**グリッド内の全結果は記録・保存し**，恣意的に都合の良い結果のみを選んで他を破棄することのないようにする。論文化の段階で，優位性が出た設定を主結果として提示しつつ，範囲全体の傾向（あるいは差が出なかった設定があればその旨）も付記できるよう，実行ログは網羅的に残す。

# 実装指示

# 実験1：Mushroomデータセットを用いた二値分類問題

## 1. 目的

`report_020.md` の実験0（a9a，非凸設定）では，本実装（SVRG，NFG SVRG，ASAI SVRG）が
NFG SVRG原論文Figure 3の挙動を定性的に再現できることを確認した．また副次的に，
(a) 学習率が理論上界 $\eta=1/(3L)$ に近い場合にNFG SVRG・ASAI SVRGが振動する現象，
(b) ASAI SVRGの近似誤差 $\|e_s\|^2$ がNFG SVRGより一貫して小さい現象，
が観察された．

実験1は，これらの観察を，ASAI SVRG論文の理論解析の前提（Assumption 1–4：L-平滑性，凸性，
µ-強凸性，分散の一様有界性）を厳密に満たす設定において定量的に検証する．具体的には次の
2点を確認することを目的とする．

1. **定理1（収束特性）の検証**：SVRGが理論の収縮係数 $\rho$ に整合する速度で線形収束し，
   NFG SVRG・ASAI SVRGは近似誤差 $\|e_s\|^2$ に起因する誤差床へ収束すること
2. **定理2（誤差床の上界比較）の検証**：ASAI SVRGの誤差床がNFG SVRGの誤差床以下となること
   （$\mathbb{E}[\|e_s^{ASAI}\|^2] \le \mathbb{E}[\|e_s^{NFG}\|^2]$）

また，実験0で観察された学習率依存の不安定化現象（`report_020.md` 5.2節）が，強凸設定でも
同様に発生するか，あるいは非凸設定に固有の現象だったかを合わせて確認する．

## 2. データセットとモデル

- **データセット**：Mushroom（UCI Machine Learning Repository）．食用／毒キノコの二値分類
  データセットであり，離散的特徴量をone-hot等の数値変換で $d$ 次元ベクトルに変換したものを
  用いる（ASAI SVRG論文の記載では $N=8124$，$d=22$．前処理方法は原論文の記載が簡潔なため，
  実装時にUCIリポジトリの元データから具体的な変換手順を決定し，レポートに明記すること）
- **モデル**：ロジスティック回帰モデル（切片項を含む）
- **目的関数**：二値交差エントロピー損失 + L2正則化
  $$
  f(w) = \frac{1}{N}\sum_{n=1}^N \ell_{BCE}(y_n, \hat{y}_n(w)) + \frac{\lambda}{2}\|w\|^2,
  \quad \hat{y}_n(w) = \sigma(w^\top x_n + b)
  $$
  この目的関数は $L$-平滑かつ $\mu$-強凸（$\mu=\lambda$）であり，Assumption 1–4を満たす．

## 3. 平滑性定数・学習率・正則化係数の決定

実験0（`report_020.md` 3.4節）と同様の手順で，データから解析的に決定し，チューニングは
行わない．

- **平滑性定数 $L$**：BCE損失の1サンプル分 $\ell_{BCE}(y_i, \sigma(w^\top x_i + b))$ の
  ヘッセ行列は $\sigma(z)(1-\sigma(z)) \cdot x_i x_i^\top \preceq \frac{1}{4}\|x_i\|^2 \cdot I$
  （$\sigma(z)(1-\sigma(z)) \le 1/4$）で上から抑えられることを用い，正則化項の寄与
  $\lambda$ を加えて
  $$
  L = \frac{1}{4}\max_i \|x_i\|^2 + \lambda
  $$
  として計算する．切片項を含む場合は $x_i$ に定数項を付加したベクトルとして扱うこと．
- **正則化係数 $\lambda$**：$\mu$-強凸性を保証する強さを持たせつつ精度を過度に劣化させない
  値として，正則化なしの平滑性定数 $L_0 = \frac{1}{4}\max_i\|x_i\|^2$ に対する比率
  （例：$\lambda = 10^{-2} \times L_0$ 程度）で決定する．具体的な比率は実装時に決定し，
  根拠（$\mu/L$ の条件数がどの程度になるか）をレポートに明記すること．
- **学習率**：実験0と同様，複数の理論的根拠を持つ学習率で比較する．
  - $\eta = 1/(3L)$（ASAI SVRG論文 補題3の条件 $0<\eta<1/(3L)$ の上界近傍）
  - $\eta$ を $\rho<1$（式(30)の収縮係数）が十分小さくなるように選んだ値（例：
    $\rho \approx 0.5$ となるよう逆算した $\eta$）
  - 実験0で安定した収束を示した $\eta=1/(20L)$ 相当の縮小版
  
  実験0の5.2節で観察された「学習率が上界に近いほどNFG SVRG・ASAI SVRGが振動する」現象が
  強凸設定でも再現するかを確認できるよう，**上界に近い学習率を必ず1つ含める**こと．

## 4. 実験条件

- **バッチサイズ**：1（オンライン学習，理論解析の設定と一致）
- **内部ループ長**：実験0と同様，ランダムリシャッフル（RR）を用い $K=N$（1エポックで全データを
  1巡）
- **比較手法**：SGD, SVRG（`SVRGFinalPoint`，最終点採用）, NFG SVRG（`NFGSVRGFinalPoint`，
  最終点採用）, ASAI SVRG（`ASAISVRG`，平均パラメータ採用）の4手法．実験0と異なり，ASAI SVRG
  は理論的検証の主対象であるため必須．
- **Seed数**：5（0〜4）
- **エポック数**：定理1・定理2の検証に十分な収束が見られるまでの回数とする．実験0（100エポック）
  を参考に，まず100エポックで実施し，SVRGの収束・NFG/ASAIの誤差床への到達が確認できない場合は
  増やすこと

## 5. 実装上の注意

- 既存の `programs/optimizers/` の各クラス（`SGD`, `SVRGFinalPoint`, `NFGSVRGFinalPoint`,
  `ASAISVRG`）をそのまま再利用すること．実験0で実装・検証済みのため，Optimizer自体の実装変更は
  不要である．
- 実験のディレクトリ構成・出力形式（`outputs/ex001_mushroom_logistic/` 等）は実験0
  （`outputs/ex000_a9a_least_squares/`）の構成に倣うこと．
- 分類精度に加え，目的関数値の真の最適解 $f(w^*)$ が既知（あるいはL-BFGS等で高精度に推定可能）
  であれば，縦軸は $f(z_s)-f(w^*)$ の差分で評価すること（強凸問題は最適解を高精度に求めやすい
  ため，実験0の「差分が取れない非凸設定」とは扱いを変える）．

## 6. 実験終了の基準

以下をすべて満たした時点で実験1を完了とする．

1. **SVRGの線形収束**：学習率 $\rho<1$ となる条件で，$f(z_s)-f(w^*)$ が片対数プロット上で
   おおむね直線的（指数関数的）に減少すること
2. **NFG SVRG・ASAI SVRGの誤差床への収束**：同条件で，NFG SVRG・ASAI SVRGの $f(z_s)-f(w^*)$
   がある値で頭打ちになり，SVRGのように最適値まで減少しきらないこと
3. **誤差床の大小関係**：ASAI SVRGが到達する誤差床（$f(z_s)-f(w^*)$ の下限）が，NFG SVRGの
   誤差床以下であること．また近似誤差 $\|e_s\|^2$ についても同様の大小関係
   （$\mathbb{E}[\|e_s^{ASAI}\|^2] \le \mathbb{E}[\|e_s^{NFG}\|^2]$）が定量的に確認できること
4. **学習率依存の不安定化の有無**：実験0の5.2節で観察された振動現象が，強凸設定でも
   学習率上界近傍で再現するか（あるいは非凸設定固有だったか）についての考察をレポートに含める
   こと
