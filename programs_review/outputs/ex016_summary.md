# ex016 の集計結果（ImageWoof・バッチサイズ128，5手法の実時間）

実時間は `elapsed_time`（$ = $ `time_optimizer + time_svrg_full_grad` の累積．評価と診断の時間を除く）である．1エポックの時間は，シードごとの2エポック目以降の増分の中央値であり，表には5シード（5周）の平均（最小〜最大）を示す．予算は $ \#\mathrm{grad}/N \le 200 $ であり，予算での値は予算以下の最後の評価点の値である．初期の時間は外側ループの前の `elapsed_time`（SVRG の初期の全勾配）である．
